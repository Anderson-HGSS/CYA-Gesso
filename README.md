# CYA-Gesso

Este se trata de um Sistema SCP (Sistema de Cadastro de Produtos e Orçamentos) proposto como projeto final do curso SaberTi, ofertado pela empresa Accion Sistemas. O sistema utiliza um banco de dados Supabase e conta com todas as funcionalidades de um CRUD padrão, além disso, é personalizado e focado para uma empresa real que trabalha no ramo de gessaria!
